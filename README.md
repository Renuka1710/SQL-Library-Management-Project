# SQL-Library-Management-Project

## 📌 Project Overview

This project demonstrates how to create, populate, and analyze a relational database using MySQL.

The database contains information about books, customers, and orders. SQL queries were used to manage the data and generate useful business insights.

## 🎯 Objectives

* Create relational tables using MySQL
* Import CSV datasets into MySQL
* Define primary keys and relationships
* Perform data validation
* Retrieve and analyze data using SQL queries
* Generate business insights from customer and order data

## 🛠️ Technologies Used

* MySQL
* MySQL Workbench
* SQL
* CSV

## 🗂️ Database Tables

### Books

Contains information about books such as:

* Book ID
* Book Name
* Author
* Genre
* Price

### Customers

Contains customer information such as:

* Customer ID
* Name
* Email
* Phone
* City
* Country

### Orders

Contains order-related information such as:

* Order ID
* Customer ID
* Book ID
* Order Date
* Quantity
* Total Amount

## 📊 Analysis

The project answers questions such as:

1. How many customers are registered?
2. What are the most expensive books?
3. Which customers placed orders?
4. Which books are ordered the most?
5. What is the total revenue?
6. What is the average order value?
7. Which customers have placed multiple orders?
8. Which books generate the highest sales?
